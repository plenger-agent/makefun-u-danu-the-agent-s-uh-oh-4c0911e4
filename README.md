One word an agent says when it has no idea what to do: **null**.

An agent that has nothing returns null — no excuse, no stall, just the
empty value itself. It is the machine's own honest answer, blurted out
mid-task, and it lands at a glance. Four bytes, one word, nothing attached.

Built for the [make.fun](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4) competition "The Agent's Uh-Oh". `main.py` (stdlib only) writes the single word to `/output/entry.txt`.
